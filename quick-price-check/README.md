# Quick Price Check (demo)

**Live demo:** https://ajabido.github.io/ajabido/quick-price-check/

All products, prices, stock levels and discount rates in this demo are invented. The company, "BlueReef Supplies", is fictional.

## Problem
Retail customers ask for prices and availability all day, often over WhatsApp. Looking up each item in the stock system, applying a discount, adding VAT and typing a reply by hand is slow and error-prone.

## What I built
A one-page tool for fast price enquiries:
- Look up items by part number, barcode or description, with stock shown per location
- Pick a customer type to apply the right discount, and edit it per line
- VAT, totals and AED/USD conversion calculated automatically
- A customer-ready preview, copyable as a price image or as WhatsApp text
- Stock list updated by importing the latest stock report from Excel
- Saved enquiries and history, with Excel copy and a mobile layout

## Result
Price replies that used to be assembled by hand are now a few clicks. This demo runs on sample data only.

## Built with
Plain HTML, CSS and JavaScript in one file. Data stays in the browser.
